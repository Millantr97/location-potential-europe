Data API preview

Static, versioned JSON endpoints expose the same published comparison rankings as the site. They are cacheable files, not a live paid backend.

EndpointUse
../api/v1/index.jsonVersion, freshness, cities, concepts and labels.
../api/v1/concepts/{concept}.jsonRanked zone records for one concept.
fetch('https://millantr97.github.io/location-potential-europe/api/v1/concepts/specialty-coffee.json')
  .then(r => r.json()).then(data => console.log(data.zones));

There is no billing, API key, SLA or private-data backend on this static GitHub Pages site. Commercial/API access needs a separate hosted service and terms. The preview is published so agencies can test the schema without a fake paywall.

Record fields

city_id, zone, fit_modelled, local modelled revenue band, EUR comparison value, latitude and longitude. Coordinates are candidate anchors, not premises availability.
