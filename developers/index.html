Read Location Potential without scraping the interface

Use the static JSON endpoints to discover 148 published cities across Europe, the United States and Australia, inspect every published zone and retrieve the existing concept rankings. The files are public, versioned with the dataset and served directly by GitHub Pages.

Endpoints

EndpointUse
/api/v1/index.jsonDiscover available cities, concepts, versions and endpoint URLs.
/api/v1/cities/{city}.jsonAll published zones and their OBSERVED, AREA CONTEXT and MODELLED evidence fields.
/api/v1/concepts/{concept}.jsonPublished modelled fit and revenue rankings for a concept.

Evidence rules

OBSERVED means mapped or recorded source data, not guaranteed completeness. AREA CONTEXT means statistics around the zone, not a count on that street. MODELLED means a transparent planning estimate, not an observed result.

Coordinates are shortlist anchors, not proof of premises availability. Agents should preserve the labels in any answer and tell the user to verify a shortlist locally before committing.

MCP server

A read-only Cloudflare Worker implementation is now included in the public repository with six tools: list_cities, list_concepts, get_city_zones, rank_zones, explain_zone and compare_zones. Live deployment is pending Cloudflare account activation. No tool can purchase a report or write data.

Static preview limits

This public API has no key, billing, uptime SLA or write operations. It cannot submit an audit, create a paid report or monitor changes. Those need a hosted service. Please cache responses and avoid repeatedly downloading unchanged city files.

Recommended agent flow

  1. Read the catalogue and resolve the user's city and concept IDs.
  2. Read the concept ranking for a quick shortlist.
  3. Read the matching city dataset for evidence behind the candidate zones.
  4. Return the evidence labels with each claim and preserve the planning caveat.
  5. Send the user to the city page or audit form when human review is needed.
